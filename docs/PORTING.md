# Porting ABIHA from Laravel to plain PHP (working spec)

The owner's rule: **the website must stay exactly as it was** (same pages, same URLs, same design, same colours, same products, same admin), only the engine changes to plain PHP 8.1+ with MySQLi, no framework, no Composer.

* **Reference (the old Laravel version, read-only):** `C:\Users\MTS\abiha-laravel-backup` (`app/`, `resources/views/`, `routes/web.php`, `routes/admin.php`, `config/`, `tests/`, `resources/css`, `resources/js`, `abiha_pk-full.sql`). Never edit it.
* **Target (this project):** `C:\xampp\htdocs\abiha.pk`, folders `app/Controllers`, `app/Core`, `app/Services`, `app/Views`, `app/routes.php`, `bin/console.php`, `database/migrations`, `public/`, `tests/`.
* **Dev database:** `abiha_pk` (data copied from the Laravel site: 99 products, 45 categories, settings, ...). Schema = `database/migrations/001_schema.sql` (identical to the Laravel schema, so the live database keeps working). Test database: `abiha_pk_test` (wiped by `php tests/run.php`).
* **URL of the dev site:** `http://localhost/abiha.pk/` (root `.htaccess` routes into `public/`).

## Runtime (already there, uravex-style core, `app/Core`)
`Router` (get/post/put/patch/delete, optional `name`, `route('name', [...])`, `route_is('name')`), `Request`, `Response`, `Session`, `Csrf` (POST/PUT/PATCH/DELETE need `_token` field or `X-CSRF-TOKEN` header; forms use `<?= csrf_field() ?>`; method spoofing with a hidden `_method`), `View::render('store/home', $data)` + layouts in `app/Views/layouts`, `Database::get()` (`all/one/value/column/exec/insert/transaction`, prepared statements only), `Validator`, `Mailer`, `RateLimiter`, `Logger`, `ErrorHandler`.

## Rules for every ported piece
1. **Same HTML, same CSS class names, same Alpine attributes** as the Blade view, so the copied compiled CSS (`public/assets/abiha/abiha.css`), JS (`public/assets/abiha/abiha.js`, Alpine, CSP-safe, reads `window.ABIHA` and `<meta name="csrf-token">`) and icons keep working. Blade -> PHP: `{{ $x }}` = `<?= e($x) ?>`, `{!! !!}` only for already-sanitised HTML, `@foreach/@if` = alternative PHP syntax, `<x-icon name="x" :size="16" />` = `<?= icon('x', 16) ?>`, `<x-logo :width="76" />` = `<?= logo(76) ?>`, `route('name', ...)` = the same helper name here. No inline `<script>` except the CSP nonce pattern the layout already uses; never inline event handlers.
2. **Same URLs and route names** as `routes/web.php` / `routes/admin.php` of the old project. Each slice registers its routes in its own file `app/routes/<slice>.php` (the loader in `app/routes.php` includes every file in that folder). Middleware strings: `auth`, `guest`, `perm:<name>`, `staff`.
3. **Data = arrays.** Services are static classes in `App\Services` (or `App\Support` for helpers) using `Database::get()`; a product is an assoc array with related lists attached under keys (`images`, `variants`, `category`...). Booleans come out of MySQLi as ints: cast when printing. Money is whole-PKR integers (`money()` helper prints `PKR 1,200`). Dates are stored in **Asia/Karachi business time**, exactly like the Laravel app (its `app.timezone`): write timestamps with the `now()` helper (PHP), never `NOW()`/`UTC_TIMESTAMP()` in SQL; the connection keeps the server's default time zone as Laravel did.
4. **Behaviour must match** the Laravel version: validation rules and messages, stock/inventory ledger rules, coupon rules, price always read from the database, payment never simulated (see "Payments" in the old `app/Services/Payments`), activity log entries, emails, SEO (canonical, noindex rules, JSON-LD), accessibility, security headers.
5. **Do not touch files owned by another slice.** Shared files (`app/helpers.php`, `app/Core/*`, `app/Views/layouts/*`, `public/assets/abiha/*`) are changed only if absolutely needed, with small additive edits; say so in your report.
6. **Tests:** add tests for your slice to the uravex-style harness (`tests/run.php`; suites `UnitTest.php`, `IntegrationTest.php`, `HttpTest.php` + `tests/Fixtures.php`). Port the intent of the old Laravel tests in `abiha-laravel-backup/tests` that belong to your slice (they are the acceptance criteria). Run `php tests/run.php` before you report.
7. **Verify visually** with the real browser helpers when a page changes: Edge headless screenshot script `C:\Users\MTS\AppData\Local\Temp\claude\00009b16b04d5545\0c03d359-62f6-4d3d-a089-a9ad2c95ae14\scratchpad\shot3.mjs` (usage: `node shot3.mjs <url> <width> <height> <out.png>`), compare with the old design (the same page in the backup is rendered by the old CSS).
8. PHP must run on **8.1** (no 8.2-only syntax: no `readonly class`, no DNF types, no `true/false/null` standalone types) and need only `mysqli`, `gd`, `mbstring`, `fileinfo`, `openssl`, `json`.
9. Never invent business data. Never delete the backup. Write files with the Write/Edit tools (shell heredocs mangle backslashes).

## Foundation API (slice F, use these; details in the class doc comments)
* **Routes**: `app/routes/<slice>.php` gets `$router`; `$router->get($path, [Controller::class, 'method'], ['auth', 'throttle:login'], 'name')`. Middleware: `auth`, `guest`, `staff` (role.is_staff, admin idle timeout), `perm:<slug>` (implies auth+staff; old `can:`), `throttle:<name>` (old named limiters, `RateLimiter::LIMITS`), `nocsrf`. `app/routes/foundation.php` only registers 404 fallbacks for chrome route names no slice has defined yet (and the placeholder home); registering the same name in your file wins, no need to edit it.
* **Controller** (`App\Controllers\Controller`): `view($tpl, $data, ['title','description','noindex','canonical','image','type','breadcrumbs','jsonld'])`, `adminView($tpl, $data, $title)`, `partial()`, `json()`, `validate($request, $rules, $messages, $attributes)` (Laravel rule names and messages, redirect back with `errors`/`old` or 422 JSON), `redirect($to, status: '...')`, `back()`, `intended()`. Views get `$errors`, `$user`, `$navCategories`, `$cartCount`, `$wishlistIds`. Page-to-layout extras: `View::share('headExtra'|'scripts', $html)`.
* **Helpers**: `e`, `cfg`, `setting`, `url`, `route` (accepts a DB row), `route_is` (`admin.orders.*`), `route_exists`, `asset`, `media($path, $width)`, `media_srcset`, `icon($name, $size, $classOrAttrs)`, `logo($width, $lazy)`, `carrier_logo`, `money`, `csrf_field`, `method_field`, `old`, `error`, `errors`, `flash`, `now`, `dt`, `str_limit`, `slugify`, `rich`.
* **Auth** (`App\Auth\Auth`): `user()` (row + `role`, `role_name`, `is_staff`, `permissions`), `check/id/isStaff/isSuperAdmin/can`, `attempt($email,$pw)`, `login($row)`, `logout()`, `refreshPasswordFingerprint()`, `hashPassword/verifyPassword`, `wasDisabled()`, `actingAs()`. Session keys kept across login for merging: `cart_token`, `wishlist_ids`, `intended`.
* **Support**: `Settings::get/put/forget`, `SiteSettings::asset/logoPath`, `Menus::get/rows/safe`, `Seo::title/description/noindex/breadcrumbs/schema/image/canonical/organization/website`, `Img::url/src/srcset/picture/dimensions/generate/delete`, `HtmlSanitizer::clean`, `CatalogCache::remember/bump` (call `bump()` after any catalogue/content write). **Services**: `ImageStore::store/storeIcon`, `ActivityLogger::log('action', 'Order', $id, $props)`, `Cart::count/current` and `Wishlist::ids` (stubs to extend), `Navigation::categories()`. **Core**: `Uploads::storePrivate` (payment proofs on the private disk), `RateLimiter`, `Mailer::sendNow/queue` (templates in `app/Views/emails`, shell `emails/layout.php`).
* **Tests**: add `tests/<Slice>Test.php` (run.php runs every `*Test.php`); helpers `reset_db()`, `Fx::user('staff')`, `Fx::product()`, `Fx::category()`, `Fx::insert()`, `Fx::image()`, `http($method, $path, $input, $user, ['json' => true, 'csrf' => false, 'headers' => []])` returns a Response.
