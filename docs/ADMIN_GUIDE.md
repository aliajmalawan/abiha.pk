# Admin guide: how to change the website's content

Everything below is done from the admin (your-domain/admin). Nothing needs a developer.
Start at **Content overview**: it lists every piece of content, whether it is done, and a button to fix what is missing.

| I want to change... | Go to |
|---|---|
| Products: name, price, photos, video, stock, description | Products (use the formatting buttons above the description) |
| Categories, collections | Categories, Collections |
| Big home page picture and its words | Banners (placement "Hero") |
| Order and look of the home page blocks, the "Our story" text | Homepage |
| Privacy policy, Terms, About us, any other page | Pages (tick "Published", and "Link from footer" to show it in the footer) |
| FAQ questions and answers | FAQ |
| Shipping policy, return policy, size guide | General settings -> Policies |
| Phone, email, address, social links, announcement bar | General settings |
| Logo and favicon | General settings -> Brand logo / Favicon icon |
| Header and footer menu links | Menus |
| Customer testimonials | Testimonials (only real customer words) |
| Shipping rates, payment methods, bank details | Shipping, Payments |
| Visitors and traffic | Analytics |

## Formatting text (Pages and product descriptions)
Above the box there are buttons: **B** bold, *I* italic, H2/H3 headings, Bullets, Numbers, Quote, Link, Paragraphs
(turns text separated by blank lines into paragraphs) and Clear (removes formatting from the selected text).
Select the words first, then press a button. **Preview** shows roughly how it will look. Only safe formatting is kept when you save.

## The FAQ
Admin -> FAQ shows the built-in questions. Change, add, remove or reorder them (groups and questions) and press **Save FAQ**.
Inside an answer you can type words like `{shipping}`, `{contact}`, `{track}`, `{payments}`: the page turns them into links or live values
(the full list is on the FAQ editor page). "Use the built-in FAQ" throws your version away.

## About us
Until you write your own text, the About us page shows a built-in page made from your real categories. To replace it: Pages -> About us -> write the
text -> Save. To go back, empty the box and save.

## Things that are never shown unless they are real
Prices, offers, delivery times, reviews and testimonials are never made up by the website. If something is empty it simply does not appear.
